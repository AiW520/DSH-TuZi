# 云朵兔

[English](README.md) | 中文

桌面辅助进程与任务事件适配器改编自 `PC2005-cloud/dsh-pet` 0.3.8（MIT）。上游许可保留于 `LICENSE`。不包含原版动画、人设提示词、表情包或字体素材。

七段云朵兔动画使用此前选定的 DSH-TuZi 素材。配置采用系统字体，关闭主动模型调用和余额轮询，将真实 Harness 事件映射为思考、工作、等待、完成和错误反馈，并保留点击及拖拽反馈。

社区改动包括：使用应用已安装的 Electron、加载固定的内置辅助入口、打开 `dsh-tuzi://open`、使用绝对路径加载辅助页面、移除运行时下载。打包流程编译 `src/index.ts`，在签名前将插件纳入运行时清单。插件由正常的 Harness 配置加载；恢复流程可随其他可选插件一起禁用它。

上游包归档的 SHA-256 为 `475316d988c8acd48237ed10514e73b331b852f952ff11659f4250c439f85a27`。macOS arm64 预览版已在安装后通过真实会话测试，覆盖 Harness 0.2.1-rc.3 的工具调用、等待、失败及取消。此结果不涵盖其他操作系统。

点击桌面云朵兔会轻跳一下，不改变当前任务或桌面位置。空闲时会自然眨眼；右键菜单提供眨眼、轻跳和减少动作。减少动作偏好保存在本地，同时遵循系统设置：视频暂停时，任务画面和消息仍然更新。拖拽、任务切换、冻结和销毁都会取消互动小动作。辅助窗口重启会恢复当前任务，不重放旧指令。闭眼 WebP 来自生成的云朵兔素材。

运行 `node community/tests/desktop-pet-interactions.mjs <electron-executable>` 检查辅助窗口；使用已安装的 DSH-TuZi 可执行文件并追加 `--installed`，可检查打包后的插件。测试使用独立配置目录和本地任务状态服务器，不调用模型供应商。
