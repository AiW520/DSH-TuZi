# DSH-TuZi 社区预览版 1

[English](README.md) | 中文

基于 DeepSeek Harness 0.2.1-rc.3 的独立社区发行版，未经 DeepSeek 或 TuZi 官方背书。首个安装包面向 macOS Apple Silicon，使用临时签名，尚无 Developer ID 签名及 Apple 公证。本版本用于预览测试，不作为面向所有用户的稳定版。

- 添加自定义模型时，依据供应商明确元数据、完整模型目录匹配和 TuZi 说明建议勾选图片输入；保留手动选择。旧接口地址的异步响应不会更改新配置。
- 默认流式空闲超时延长至十分钟，临时错误最多重试八次；已有明确配置保持不变。TuZi 容量不足作为临时服务器错误处理，认证失败仍归为认证错误。
- 云朵兔复用 dsh-pet 的 MIT 事件和交互代码，采用独立素材，共用应用内置 Electron。真实 Harness 会话驱动思考、工作、完成、等待、错误和取消反馈。
- 应用标识、协议、设置及数据目录独立，可与原版共存。关闭上游遥测；本未公证预览包保持关闭自动升级。

2026 年 10 月 28 日已构建 macOS DMG，挂载并复制到独立安装目录，执行 `codesign --verify --deep --strict` 后实际启动。安装后的应用通过本地模拟供应商进行真实会话、工具和桌宠联动测试，未发现渲染页面脚本错误。包内 CLI 插件安装与移除，以及 DOCX/XLSX/PPTX 转 PDF 冒烟测试通过。完整构建及聚合 TypeScript 检查通过，相关模型识别、配置、转换、取消和打包测试通过。

使用 `gpt-6.1-terra` 经 TuZi 自定义通道发送真实图片请求，成功识别二维码；整项测试约 76 秒。所提供账户的模型列表未返回 Claude 路由，故 Claude 真实兼容性尚未验证。单次成功请求不代表长期稳定性，也不覆盖所有模型。Windows、Intel Mac 和 Linux 安装包尚未完成本轮验收。

文档同步最初出现三项失败，其中双语配对和生成配置目录已修复并复查。仍有一项上游引用检查将 `python/sdk/uv.lock:113` 的 wheel 文件大小误认成提交号缩写。此项明确记为已知检查失败，不宣称通过。
